# Contributing

1. Create a feature branch.
2. Keep each change focused and explain behavior changes in the commit or pull request.
3. Open a pull request against `main`.
4. Wait for the **Build** workflow to finish and inspect its artifact/logs.
5. Do not claim a Minecraft/Controlify version is supported until the build and relevant in-game behavior have been verified.

The build workflow runs for every pushed commit and for pull requests.
